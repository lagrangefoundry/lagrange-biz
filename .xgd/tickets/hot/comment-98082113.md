Sweep 2026-08-18. Operator raised two open questions about install that this goal realized state does not cover, and neither has a ticket:

1. **Binary install?** v1 is install.sh served from xgd.dev, bootstrapping a Python package. A binary distribution is a different artifact with a different build, signing and update story - it would be packaging v2, not a fix to this goal. Do not reopen this goal for it.
2. **What is the role of gh?** Unresolved. XGD uses the gh CLI in its workflows, which makes it an install prerequisite the installer does not currently handle - a beta user without gh authenticated hits it at first reconcile, not at install time. This is the kind of thing that reads as a broken product rather than a missing dependency.

Both belong under xgd/GOAL-2 (Packaging with an update path, planned) rather than here. Flagging rather than filing - the binary question is a product decision, not a bug.
